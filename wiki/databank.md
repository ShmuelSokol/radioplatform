# Databank (KBR Studio's database window)

`/admin/databank` copies the "KBR Database 1.82" window of the station's old program: the library as plain black-and-yellow tables you sort by clicking a column, with Find, ALL, Edit mode, a headphones (pre-listen) button and a Page / Rec / View / Tot status bar. Tabs: Songs (Songs.db), Jingles, Spots (Spots.db), Blocks (Blocks.db), Log. Opened from the control room's **DB** button (phone: the Played pane's Databank button) and Content > Databank.

Backend: `api/v1/databank.py` (staff to read, managers to change).

- `GET /databank/items` pages the library (max 500 a page) sorted on the server by artist, title, type (= `category`), vote (V), length, intro, file, last_played or added. Last played is a grouped `max(play_log.start_utc)` per asset, for the chosen station. Dated time/weather recordings are left out, like the cart. Find is literal: `%`, `_` and `\` are escaped before LIKE ("track_01" finds only that).
- `GET /databank/types?asset_type=` lists every type (category) of the whole table, one spelling each. The Type filter and the Edit-mode list use it, so a type that first shows on page 3 can be picked from page 1.
- `GET /databank/spots` lists every `asset_type="spot"` with its category, length and an **end date** = the latest `end_date` of the spot schedules that air it (open-ended if any schedule has none). Expired (end before the station's today) is drawn red, like the old program. The old program kept the end date on the spot; here it lives on `SpotSchedule`, so `PATCH /databank/spots/{asset_id}/end-date` moves the end date of *every* schedule of that spot (on that station) and refreshes the queues the same way the Spot Schedule page does. A spot with no schedule answers 409. Without `station_id` the API moves the spot on every station (each checked against the manager's stations); the page never does that: it always sends the chosen station and says "Choose a station first." while none is chosen. Clearing the end date (empty box, or the iPhone date wheel's Clear, which saves on leaving the box) asks first, since the spot then airs for ever.
- `GET /databank/log?station_id&day=YYYY-MM-DD` is one station-local day of `play_log`, oldest first, up to 5000 rows; the page shows each play as a Started and an Ended line to the millisecond (`controlroom/DayLog.tsx`), with the last 14 days in a list on the left (a drop-down on a phone). The list follows the station's clock (looked at every 30 s), so a page left open over the station's midnight moves on to the new day; a day picked from the list stays.

Blocks tab reads `/program-blocks` (managers) and shows one row per clock time. Week days are written the old way, **0 = Sunday … 6 = Saturday** ("012345" = Sunday to Friday), converted from our 0 = Monday by `kbrWeekdays()`. The yellow dot (Flg) means a hard block. Editing blocks stays on the Program Blocks page.

Dates on this page are day-first (14/12/2026), as the old program writes them; the rest of the site is US style.

Edit mode (managers): click or tap Artist, Title, Type, V or Intro on a song (on a phone card: Title, Type, V), Category or End date on a spot; Enter saves (`PATCH /assets/{id}`), Esc cancels, leaving a changed box saves. Pressing Edit mode to turn it off closes an open cell without saving (the press would otherwise blur the box and save it). While a new sort or page loads, the old rows stay dimmed and cannot be edited. The edit box is 16 px on phones so iPhone does not zoom. Choosing a station here also makes it the control room's station ("Control room" opens on it). Dates are built as d/m/yyyy without padding (8/10/2026).

Mpeg / Prsnt filters and 123 (go to record): see [station-modes](station-modes.md). Not copied: BLK PRE SPOT, "blank" jingles of a set length.

Test: `frontend/e2e/databank.mjs` against a running site with data (desktop and iPhone); `frontend/e2e/databank-screen.mjs` against a fake backend (every screen row: desktop 1366x768, iPhone 13 and SE, landscape, tablets; `ONLY=<part>`); `backend/tests/test_databank.py` and `test_databank_rows.py` (sorts, filters, spots and end dates with queue refresh, day-log edges on clock-change days, roles, errors, speed on 23,000 songs, activity log).
